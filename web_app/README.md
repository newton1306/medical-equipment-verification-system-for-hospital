# Phusing Hospital - Equipment Verification

ระบบถูกพัฒนาด้วยเทคโนโลยี:
- FastAPI (Backend)
- OpenCV (Vision Processing)
- Gemini VLM (AI Verification)
- PWA (Mobile-first Frontend)
